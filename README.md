# EHU-SRDSI

Prácticas de Seguridad en Redes y Servicios (SRDSI). Autores: Jorge Arévalo y Jon González.

- `lab-pki/` — PKI privada (rootCA + subCA): scripts `openssl`, configs e informe-bitácora en Markdown → PDF.
- `lab-openssh/` — ejercicios SSH.
- `lab-ssl/` — SSL/TLS (teoría + código C cliente/servidor).
- `ascon/` — benchmarks Ascon.

La VM del laboratorio (`SRDSI_Debian13/`, VirtualBox, usuario `user1`, host `bocata-jamon`) no se versiona.
